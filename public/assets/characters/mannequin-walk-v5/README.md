# mannequin-walk/v5

사용자 승인된 ANNY r3 MoMask 보행의 쉐이딩 강화 32프레임 관리 원본이다. 4방향 × 8프레임, 512×512, 프레임당 150ms. rig-sheets 및 pose-sheets는 방향당 4×2 배열이다.

제작 자산·리그·코드는 slime-workflow의 assets/motion-sheet/mannequin-walk-v5에 보관한다. OpenPose 맵은 리그 관절 투영이며 검출기 추론 결과가 아니다. 등록은 보관 목적이며 게임 런타임에 자동 적용하지 않는다. ANNY-LICENSE.txt를 함께 유지한다.
