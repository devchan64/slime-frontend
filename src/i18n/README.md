# 언어팩 사용

기본 언어는 한국어(`ko`), 추가 언어는 영어(`en`)입니다. 헤더에서 선택하면 즉시 반영하며 `slime.locale`에 저장합니다. 문서의 `lang` 속성도 갱신합니다.

## 파일 구성

- `locales/{언어}/common.yaml`: 공통 메뉴
- `locales/{언어}/auth.yaml`: 로그인·가입 안내
- `locales/{언어}/character.yaml`: 게임 진입 및 미배분 포인트 확인
- `locales/{언어}/field.yaml`: 활동포인트·지형 범례

컴포넌트에서 `const { t } = useTranslation()`을 호출한 뒤 `t('common.settings')`처럼 사용합니다. 치환은 `t('field.next', { seconds: 30 })` 형태입니다. 번역은 텍스트로 렌더링하며 HTML로 삽입하지 않습니다.

새 문구는 모든 언어의 같은 파일에 같은 키로 추가합니다. 중복 키, 빈 값, 비문자 값, 키 누락·추가, 치환 변수 불일치는 오류입니다. `npm run check:i18n`으로 검사하며 빌드에서도 자동 실행됩니다. 새 언어를 추가할 때는 런타임 Locale 타입·허용 언어, 선택 메뉴, 검증 스크립트의 허용 언어를 함께 수정합니다.

현재 서버 콘텐츠(맵·몬스터·스킬·업적 이름), 서버 오류 및 시스템 메시지, 전투 상세 설명과 캐릭터 성장 상세 화면은 원문을 유지합니다. 플레이어 이름·채팅은 번역 대상이 아닙니다. 미등록 번역 키를 한국어로 숨겨 대체하지 않고 오류로 처리합니다.

언어팩은 Vite 번들에 포함되어 기존 정적 배포를 사용합니다. 추가 번역 API·외부 서비스는 없습니다.
