# 기본 캐릭터 스탠딩 v4

방향별 4×1 시트 네 장. 원본 2172×724 RGBA, 셀 543×724, 방향당 4프레임·400ms·1.6초 반복이다. 생성 출처는 2026-09-20_21-53-32이며 2×2 베이스라인 v2를 참조했다. PNG 픽셀은 변경하지 않았다.

`idle-v4.animation.json`의 rect는 각 방향 시트의 로컬 좌표다. 런타임은 방향별 텍스처를 먼저 선택한다. `source.json`은 시트 해시와 각 프레임의 화면 왼쪽/오른쪽 신발 접지점을 기록한다. 각 발의 앞꿈치·뒤꿈치 끝점의 중간을 발 중심으로 정하고, 최종 앵커는 두 발 중심의 x·y 산술평균이다. 네 끝점은 footprintEndpoints에 보존한다. 단순 셀 중앙이나 양발 중 낮은 발의 높이를 사용하지 않는다.

발 좌표는 워크플로우 `generators/animation/review_standing_anchors.py`에서 하단 밝은 신발 영역을 분리하여 추정하고 오버레이로 검수했다. 신발별 하단 외곽선의 양끝에서 너비 12% 안쪽 점을 앞꿈치·뒤꿈치 후보로 추정한다. 최하단 점을 앵커로 사용하지 않는다. 후보 끝점은 검수 도구에서 수동 수정할 수 있다. 다른 신발 색상에는 검수한 좌표를 명시해야 한다.

모든 방향에 하나의 고정 배율(60 / referenceBodyHeight)을 사용한다. 프레임마다 크기를 바꾸지 않는다. 설정 초상화는 우하 시트의 같은 앵커를 사용한다. 기존 standing-v3 시트·메타데이터는 폐기했다. 2048×512 납품 목표와 다른 원본 크기를 유지한 사용자 채택 예외다.

현재 좌표는 사용자가 제공한 character-default-standing-v4-anchor-review.json의 16프레임별 두 발 중심 정수 좌표를 독립 적용했다. 시트 해시·프레임·셀 영역·앵커 계산을 검증했다. 끝점은 제공되지 않았으므로 footprintEndpoints는 비어 있으며 입력 해시와 적용 방식은 manualCorrection에 기록한다. 검수 실행은 2026-09-20_22-38-18이다.
