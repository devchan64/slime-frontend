# 기본 캐릭터 걷기 v2

지정된 4방향 ImageGen 리포트를 게임 이동 애니메이션으로 채택했다.

- 384×384 셀, 6열×4행. 행 순서는 좌하·우하·좌상·우상.
- 방향마다 6프레임, 250ms/프레임(4FPS), 1.5초 반복.
- 발 기준점 (192, 368), 기준 몸 높이 352px를 게임 캐릭터 높이에 맞춘다.
- 원본 픽셀은 재생성·리사이즈하지 않고 그대로 배치했다. 출처와 해시는 source.yaml에 기록한다.
- 필드·전투의 이동 보간 중 재생하며 정지하면 기존 대기로 돌아간다. 짧은 이동 사이에도 재생 위상은 유지한다.
