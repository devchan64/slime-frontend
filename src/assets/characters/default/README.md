# 기본 캐릭터 에셋

- `baseline/`: 승인된 2×2 외형 원본과 sidecar.
- `standing-v4/`: 현재 맵 스탠딩·설정 초상화 시트와 재생 메타데이터.
- `walk-v1/`: 4방향×8프레임을 384px 셀·4×4 두 장으로 통합한 승인 걷기 시트와 앵커 메타데이터.
- `rest-v1/`: 휴식 시트와 재생 메타데이터.
- `cutins/`: 기본 펀치 Action Cut-in.

파일명·버전·이미지 관리 ID는 유지한다. 생성 실험은 이 경로에 저장하지 않는다. 신규 미채택 후보만 워크플로우 `.tmp`에 보관한다.
