# 기본 캐릭터 대기 v6

사용자가 채택한 ImageGen 변환 16장을 384×384 RGBA 셀로 축소해 4×4 시트 한 장으로 구성했다. 시트 크기는 1536×1536이다.

| 행 (위→아래) | 방향 | 열 (왼쪽→오른쪽) |
| --- | --- | --- |
| 1 | 전방 좌측 `down_left` | 원본 1·5·9·13 |
| 2 | 전방 우측 `down_right` | 원본 1·5·9·13 |
| 3 | 후방 좌측 `up_left` | 원본 1·5·9·13 |
| 4 | 후방 우측 `up_right` | 원본 1·5·9·13 |

각 방향은 250ms × 4프레임, 1초 주기로 반복한다. `idle-v6.animation.json`은 공개 셀 애니메이션 계약을 유지한다. `source.json`은 원본 리포트·프레임별 SHA-256·시트 해시·축소 방식·발 기준점을 보존한 산출물 sidecar다.

전체 1254×1254 캔버스를 비율 유지 축소했으며 자르거나 신체를 재생성하지 않았다. 반투명 가장자리는 premultiplied-alpha Lanczos로 축소했다. 발 기준점은 alpha 128 이상 영역의 하단 중앙이며 프레임별 기준점을 런타임에서 정렬한다. 원본의 체형·높이 편차는 남아 있다.

필드·전투 대기, 캐릭터 초상화, 피격 컷인은 이 시트를 공유한다. 런타임은 프론트엔드 안의 파일만 읽는다. 이전 기본 캐릭터 방향별 시트는 교체했으며 Git 이력으로 복구할 수 있다. 몬스터의 기존 버전 경로·관리 ID는 유지한다.

## 승인 정렬 반영

저장 이력 `20260927T141349-d2f92b00`의 16프레임 정렬을 적용했다. 모든 배율이 1이므로 시트 픽셀을 재가공하지 않고 각 프레임의 기준점을 `(anchorX - x, anchorY - y)`로 기록한다. 이는 편집기의 공통 출력 기준점에 대한 이미지 상대 배치와 같다. 대기·초상화·컷인은 공통 애니메이션 메타데이터를 사용하며, 출처와 원본 정렬값은 `source.json`의 `alignment`에 보존한다.
