# 기본 캐릭터 걷기 v1

사용자의 걷기 생성·교체 지시에 따라 등록한 방향별 8프레임 시트다. Codex 내장 image_gen으로 방향마다 4프레임씩 두 번 생성하고 픽셀 패킹으로 통합했다.

- 시트 4장: 2560×1280 RGBA, 4열×2행, 셀 640×640.
- 방향별 8프레임, 150ms, 1.2초 루프.
- 2×2 승인 베이스라인 v2 및 MoMask 기반 five-head-walk-8f/v1 리그 참조.
- 좌상 4번·우상 1번은 방향 오류를 개별 생성하여 교체했다.
- 앵커는 검수 시작용 임시 정수 좌표다. 정확한 지면 접지점·루프 품질은 워크프레임 관리도구에서 검수한다.
- 게임 런타임 채택 전 에셋 등록 상태다. 스탠딩·휴식의 승인 앵커는 변경하지 않았다.
- 출처·해시는 source.json, 셀·재생 계약은 walk-v1.animation.json에서 관리한다.
