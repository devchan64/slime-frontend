# 기본 캐릭터 걷기

사용자가 승인한 Qwen AnyPose + Codex 이미지젠 보정 결과를 반영한 걷기 에셋이다.

- `walk-down.png`: 1–2행 좌하 1–8번, 3–4행 우하 1–8번.
- `walk-up.png`: 1–2행 좌상 1–8번, 3–4행 우상 1–8번.
- 각 시트 1536×1536 RGBA8, 4×4 배열, 셀 384×384.
- 방향별 8프레임, 프레임당 150ms.
- 셀·재생 계약은 `walk-v1.animation.json`, 관리번호·출처는 `source.json`. 관리번호는 워크플로우 이력과 동일하다.
- `approved-frames/`는 승인된 개별 생성 원본이다.
- 앵커는 임시 좌표이며 검수 대기다. 게임 런타임 연결은 별도이며 현재 에셋 등록 상태다.
