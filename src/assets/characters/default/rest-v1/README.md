# 캐릭터 휴식 표시

`rest-v1.png`는 1254×1254 투명 PNG이며 627×627 셀 네 개를 사용한다. 픽셀을 분할 저장하지 않고 런타임 텍스처 프레임으로 참조한다. `rest-v1.animation.json`의 `character.default.white-shirt.rest` ID와 버전 1로 관리한다.

상단은 down_right·down_left, 하단은 up_right·up_left다. 각 기준점은 앉은 몸과 다리의 지면 접촉 중심이며 현재 타일 중심에 정렬한다. 방향별 단일 프레임을 유지한다. 이미지 관리 ID는 루트 image-assets.yaml에 등록한다.
