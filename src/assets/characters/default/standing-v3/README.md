# 기본 캐릭터 스탠딩 v3

2026-09-20 사용자 채택. 2×2 베이스라인 v2와 명시적 5등신 단축 프롬프트로 생성한 PNG 원본을 사용한다. 출처: slime-workflow/.tmp/2026-09-20_21-32-33. 실제 크기 1254×1254이며 2048×2048 납품 목표에는 미달한다. 확대·재생성하지 않았다.

원본에 방향 혼합이 있어 메타데이터로 방향별 셀을 선택한다. 아래 좌표는 0부터 시작하는 (행,열)이다.

- 좌하: (2,0), (2,1), (2,2), (2,1). 원본의 고유 좌하 프레임이 3개여서 왕복 반복한다.
- 우하: (3,0), (3,1), (3,2), (3,3).
- 좌상: (0,0), (0,1), (0,2), (1,1).
- 우상: (1,0), (0,3), (1,2), (1,3).

(2,3)의 추가 우하 그림은 PNG에 보존하지만 클립에서는 사용하지 않는다. 프레임당 400ms, 주기 1.6초다. anchor는 셀 하단 신발 알파 영역의 가로 중심·최하단으로 정렬한다. 신발 원근과 자세 변화의 완전한 접지 보정은 별도 검수 대상이다. 비율·루프의 미술 품질을 자동 승인한 것으로 간주하지 않는다.

기존 standing-v2 PNG·메타데이터는 폐기했다. 필드·전투 및 캐릭터 설정/선택 초상화가 이 에셋을 공유한다.
