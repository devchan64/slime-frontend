# 기본 캐릭터 스탠딩 v2

기본 외형의 4방향 × 4프레임 투명 PNG 생성 후보다. 위에서부터 down_left, down_right, up_left, up_right이며 각 행을 왼쪽부터 재생한다. 프레임당 400ms, 1.6초 반복이다. `idle-v2.animation.json`은 CellAnimationData 계약을 따른다.

원본 픽셀과 알파는 수정하지 않았다. 발 anchor는 각 프레임의 불투명 양쪽 밑창 접촉부 중심을 각각 구한 중간점에 맞춰 보정했다. 셀 중심을 일괄 사용하지 않는다. 발 위치·프레임 정렬·루프 연결·외형 및 조명 일관성 검수가 필요하다. `standingActors.ts`에 등록되어 필드·전투에서 반복 재생한다. 런타임 연결과 미술 검수 완료는 구분한다.

5등신 비율 수정본이다. v1의 큰 머리를 축소하고 몸통 비율을 조정했다. 정확한 관절 기준 실측이나 런타임 재생 수용을 완료한 것은 아니다.
