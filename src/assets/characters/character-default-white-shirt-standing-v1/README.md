# 기본 캐릭터 스탠딩 v1

기본 외형의 4방향 × 4프레임 투명 PNG 생성 후보다. 위에서부터 down_left, down_right, up_left, up_right이며 각 행을 왼쪽부터 재생한다. 프레임당 400ms, 1.6초 반복이다. `idle-v1.animation.json`은 CellAnimationData 계약을 따른다.

원본 픽셀과 알파는 수정하지 않았다. 발 anchor는 요청 기준인 셀 (50%, 85%)이며 실측 보정값이 아니다. 발 위치·프레임 정렬·루프 연결·외형 및 조명 일관성 검수가 필요하다. 게임 런타임에는 아직 연결하지 않았다.
