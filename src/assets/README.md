# 프론트엔드 에셋

## 애니메이션 한국어 표시 이름

`animation-labels.yaml`은 워크프레임 관리도구가 사용하는 한국어 라벨 원본이다. `schemaVersion: 1`, `animations` 목록의 `animationId`와 `displayNameKo`를 관리한다. ID는 `.animation.json`의 `animationId`와 정확히 일치해야 하며 표시 이름에는 대상과 동작을 함께 적는다. 버전은 애니메이션 데이터에서 붙이므로 이름에 중복하지 않는다.

새 애니메이션 등록 시 이 목록에도 이름을 추가한다. 같은 ID의 여러 버전은 하나의 라벨을 공유한다. 관리도구는 누락·중복 ID, 중복 YAML 키, 알 수 없는 필드, 빈 값·비문자 값·한글 없는 표시 이름을 거부한다. 게임 재생 메타데이터 계약은 유지한다.
